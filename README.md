# ChannelIQ — Multi-Channel Analytics Platform

A production-grade analytics platform that aggregates performance data from multiple content channels with **database-level aggregation**, **Redis caching**, and **shareable URL-based reports**.

## 🎯 Overview

ChannelIQ lets marketing and content teams:
- **Compare** performance across YouTube, Twitter, Instagram, TikTok, Newsletter, and Blog channels
- **Aggregate** impressions, engagements, clicks, conversions, and revenue over time
- **Visualize** trends with interactive charts
- **Share** report URLs with teammates (all filters embedded in the query string)
- **Export** reports to CSV
- **Cache** results in Redis for sub-100ms repeat queries
